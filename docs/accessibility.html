Accessibility Statement

Comixplain is committed to ensuring digital accessibility for all users, including people with disabilities. We continuously strive to improve the usability and accessibility of our website and to provide an inclusive experience for everyone.

This website has been developed with consideration for the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA, and compliance with these guidelines is expected across the website.

Accessibility Features

The website includes several accessibility features designed to support users with different needs and assistive technologies.

Screen reader navigation is supported through the use of semantic HTML structures, landmark regions, descriptive headings, accessible forms and controls, clear link descriptions, and a "Skip to content" link to facilitate keyboard and assistive technology navigation.

Keyboard accessibility has been considered throughout the website. Interactive elements can be accessed using the keyboard, and modal dialogs receive keyboard focus automatically when opened. While a modal is active, keyboard focus remains within the modal and does not move to other elements on the page.

The website does not include flashing content, blinking effects, or disruptive animations.

Text and interface components have been designed to provide sufficient contrast, and images and interface elements were reviewed to support readability and visual accessibility.

The website has been tested using multiple assistive technologies and platforms, including:

  • NVDA on Microsoft Windows
  • TalkBack on Android
  • VoiceOver on iPadOS

Accessibility checks and manual reviews were performed to support compatibility with screen readers, keyboard navigation, and responsive layouts.

Known Limitations

Some content linked from the website may be provided by third parties or community contributors and may not fully conform to accessibility standards. This includes external PDF files, Android applications, interactive tools, and external websites shared as community contributions.

While we encourage contributors to consider accessibility in their materials, we cannot guarantee the accessibility of all externally hosted or community-provided resources.

Feedback and Contact Information

We welcome feedback regarding the accessibility of the Comixplain website. If you encounter accessibility barriers, experience difficulties accessing any content, or would like to report an issue, please contact us: victor.oliveira@ustp.at

We will make reasonable efforts to address accessibility concerns and improve the user experience for all visitors.
